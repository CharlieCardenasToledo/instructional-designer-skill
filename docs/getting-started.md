# Primeros pasos para docentes

1. Instala Jintia Desktop y completa la configuración institucional.
2. Selecciona una carpeta de proyectos y una plantilla.
3. Configura NotebookLM si usarás fuentes del curso.
4. Crea un curso desde Desktop o ejecuta `npx @charlie.act7/jintia init ./mi-curso`.
5. Completa el `README.md` con el sílabo canónico.
6. Ejecuta `npx @charlie.act7/jintia syllabus validate ./mi-curso/README.md`.

Las guías y PDFs se generan dentro del curso. Jintia no sustituye el contenido
del sílabo existente sin una operación explícita.
