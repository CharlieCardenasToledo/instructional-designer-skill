# Plantillas

Jintia incluye `elegantbook-clasico` y `kaohandt-marginal`. La plantilla activa
determina macros, bloques, ubicación de márgenes y capacidades visuales.

Desde Desktop puedes previsualizar otra plantilla sin cambiar la activa. Desde
la CLI puedes revisar el catálogo con el diagnóstico y compilar usando la
plantilla declarada por el curso.
