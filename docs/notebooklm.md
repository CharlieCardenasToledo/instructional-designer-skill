# NotebookLM

NotebookLM es una integración opcional para contrastar afirmaciones con las
fuentes del curso. Configura el notebook desde Desktop o `config/notebooks.json`.

Jintia debe comprobar autenticación, seleccionar el notebook y conservar la
procedencia devuelta. Si no hay sesión o fuentes locales suficientes, debe
declarar la limitación; nunca inventar citas.
