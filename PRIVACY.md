# Política de privacidad de Jintia

Jintia Desktop y la skill Jintia no incorporan telemetría ni envían contenido
a un servidor propio de Jintia.

Las funciones que requieren red se ejecutan solo cuando el usuario las
solicita. Entre ellas están la consulta de NotebookLM, la extracción de una
paleta desde un sitio web y la descarga de dependencias. Esos servicios
procesan datos según sus propias políticas.

La configuración institucional, las asignaturas, las rutas locales y el
registro de notebooks se guardan en el equipo del usuario. Los paquetes
exportados pueden contener esa configuración; deben revisarse antes de
compartirlos.

El plugin solicita acceso de lectura y escritura únicamente para producir y
validar los archivos académicos que el usuario coloca dentro de la tarea.

Para reportar un problema de privacidad, use el sistema de issues del
repositorio oficial.
