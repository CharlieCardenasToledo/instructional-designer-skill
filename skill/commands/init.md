# `/jintia init`

Prepara una carpeta de curso sin sobrescribir un sílabo existente.

Uso determinista:

```bash
node "<skill-root>/bin/jintia.js" init ./mi-curso --code IFT200 --name "Interacción Persona Computador"
```

Después, completa `README.md` con el contrato de `references/esquema-silabo.md`.
